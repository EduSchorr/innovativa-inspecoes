# Innovativa Inspeções SST

### PWA para checklists e levantamentos de campo em SST

Protótipo responsivo para organizar empresas, modelos de checklist e inspeções de campo em um único fluxo.

## O que o projeto demonstra

- Dashboard operacional responsivo;
- perfis Técnico, Gestão e Administrador;
- busca, filtros e status de inspeções;
- cadastro visual de empresas e usuários;
- criação, importação e duplicação de modelos;
- respostas rápidas **Sim / Não / N.A.**;
- campos de texto e fotografia;
- progresso por seção;
- persistência local com `localStorage`;
- manifest PWA e service worker;
- indicador de preenchimento e conformidade;
- ajustes de formulário para iOS;
- orientação para entrada por voz.

## Arquitetura

A edição v0.1 é propositalmente focada no frontend: HTML, CSS, JavaScript, armazenamento local e recursos PWA.

Ela não representa autenticação de produção, API central, auditoria corporativa ou sincronização robusta entre dispositivos.

## Privacidade

Empresas, CNPJs, usuários e e-mails da edição pública são sintéticos.
