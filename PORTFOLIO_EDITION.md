# Portfolio Edition

This repository is a sanitized public representation of the Innovativa SST inspections prototype.

The source package contained demonstration records that resembled real operational data. Before publication, the portfolio edition replaced:

- company names;
- CNPJ numbers;
- user names;
- e-mail addresses;
- example schedule references.

The public data is synthetic and uses reserved `example.com` addresses.

No production backend, authentication service, central database, API credential or robust synchronization layer exists in this v0.1 package. The README deliberately reflects only the behavior supported by the source.
